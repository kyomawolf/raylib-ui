### Overview
 raylib-ui is an ui library intended to be used for more complex ui; i. e. game development or other multi layered ui setups.

 Use simple buttons with callbacks and simple text fields to create a basic ui. These are the basic ui types, but more are soon to be implemented.

This library uses [raysan5's](https://github.com/raysan5) [raylib](https://github.com/raysan5/raylib) as basis. I.e.: (in the future) all logging is done with the builtin TraceLog.

This library uses raylibs graphic framework.
